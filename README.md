# ClearAccess («Прозрачный доступ») — Система контроля и управления доступом (СКУД)

**Проект:** Разработка прототипа легковесной системы контроля и управления доступом (СКУД).  
**Этап 1:** Подготовка среды разработки, структуры проекта и базовых модулей.

---

## 🎯 Описание проекта
Существующие системы контроля доступа (СКУД: «Болид / Орион», «Gate», «1С: СКУД») перегружены сложными техническими меню и интерфейсами.  
Цель проекта **ClearAccess** — создать понятное и быстрое решение для сотрудников охраны и администраторов с мгновенным поиском по фамилии, удобным журналом событий и выдачей разовых пропусков за 2 клика.

## 📁 Структура проекта (Этап 1)

```text
clear_access/
```

## 🚀 Инструкция по развертыванию и запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_АККАУНТ/clear_access.git
cd clear_access
```

### 2. Создание и активация виртуального окружения Python
**На Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**На macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск приложения
```bash
python main.py
```

### 5. Запуск тестов
```bash
python -m unittest tests/test_core.py
```
